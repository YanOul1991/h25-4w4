# Conception d'une interface web pour un club de voyage - __Mondo Voyages__

### Ce projet, réalisé dans le cadre du cours de Web 4W4, consiste à créer une interface fonctionnelle avec des pages qui s'affichent de façon dynamique. Ce projet est réalisé grâce aux outils de WordPress et sera déployé sur le serveur Web Hosting Canada (WHC).
